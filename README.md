# 💙 Dart Training

Coleção de resoluções de problemas da plataforma [beecrowd](https://www.beecrowd.com.br/) desenvolvidas em **Dart**. O objetivo deste repositório é praticar a sintaxe da linguagem, lógica de programação, estruturas de dados e algoritmos.

## 📁 Estrutura do Projeto

O projeto é estruturado como um aplicativo Dart em linha de comando padrão:

```text
.
├── bin/          # Pontos de entrada executáveis das soluções
├── lib/          # Funções utilitárias, lógica dos algoritmos e bibliotecas auxiliares
└── test/         # Testes unitários para validar o funcionamento das soluções
```
